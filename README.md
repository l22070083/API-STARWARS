Esta es la Prueba de una API de Star Wars el cual se llama "SWAPI"

esta es una API pública que proporciona información sobre el universo de Star Wars. La API ofrece datos sobre personajes, películas, naves espaciales, vehículos, especies y planetas que aparecen en las películas, series y otros medios relacionados con Star Wars. Esta API devuelve únicamente datos de texto (en formato JSON).
